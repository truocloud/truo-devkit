## Los mismos treinta segundos, en cuatro superficies

Cada operación de la API existe como llamada HTTP, como comando del CLI, como
método del SDK y —cuando salga— como acción de MCP. **Las cuatro se generan del
mismo contrato**, así que no pueden contradecirse.

<Tabs syncKey="superficie">
<TabItem label="curl">

```bash
curl https://api.truo.cloud/v1/services \
  -H "Authorization: Bearer $TRUO_TOKEN"

curl https://api.truo.cloud/v1/vps/svc_10432/power \
  -X POST \
  -H "Authorization: Bearer $TRUO_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action":"stop"}'
```

</TabItem>
<TabItem label="CLI">

```bash
truo auth login
truo services list
truo vps power svc_10432 stop
```

</TabItem>
<TabItem label="SDK">

```ts
import { TruoClient } from "@truocloud/sdk";

const truo = new TruoClient();               // lee TRUO_TOKEN

for await (const svc of truo.services.listAll()) console.log(svc.id);

const op = await truo.vps.power("svc_10432", { action: "stop" });
await truo.operations.wait(op.id);
```

</TabItem>
</Tabs>

## Qué se puede operar

VPS · DNS · bases de datos administradas · contenedores · balanceadores ·
Object Storage · Mail Gateway. **103 operaciones** en total —
[la referencia completa](/referencia/vps/).

WordPress, cPanel, dominios, tickets y facturación llegan en `v1.1`. Lo que no
está en [`/v1/openapi.json`](https://api.truo.cloud/v1/openapi.json) no tiene
contrato todavía.
